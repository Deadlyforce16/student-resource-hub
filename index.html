How this site uses Azure

  • Azure Static Web Apps hosts the site on the Free plan: no server to manage (PaaS).
  • Automatic HTTPS and global content delivery are included.
  • GitHub Actions redeploys the site automatically after every code change.
  • Consumption-based and free: the Free plan costs nothing within its quotas.
